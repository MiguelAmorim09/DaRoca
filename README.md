# 🌾 DaRoça --- Site de Empresa Fictícia

> Projeto escolar voltado à criação de um site completo para uma empresa
> fictícia do setor agroalimentar, idealizado e desenvolvido por
> **Miguel Henrique Amorim Pereira** e **João Torres**, alunos do
> **Colégio Técnico da Unicamp**.

------------------------------------------------------------------------

## 🧭 Sobre o Projeto

O **DaRoça** é um site desenvolvido como parte de um projeto escolar,
com o objetivo de simular a presença digital de uma empresa fictícia.\
O projeto foi inicialmente **planejado no Figma** e, posteriormente,
**implementado em HTML e CSS**.

O site contém as seguintes páginas:

-   🧍‍♂️ **Página de Cadastro:** permite que novos usuários se registrem.\
-   🔐 **Página de Login:** autenticação de usuários cadastrados.\
-   🥕 **Página de Produtos:** exibe os produtos "DaRoça", simulando um
    catálogo de vendas.\
-   🌱 **Página Institucional:** apresenta informações sobre a empresa,
    sua missão, visão e valores.

## 🌟 Objetivo Educacional

O projeto **DaRoça** foi desenvolvido com o propósito de: - Aplicar
conhecimentos de **desenvolvimento front-end (HTML e CSS)**;\
- Explorar **conceitos de usabilidade e design responsivo**;\
- Praticar o **planejamento de interface no Figma**;\
- Simular o **desenvolvimento de um site institucional** de forma
completa.
